Project · AI agent

Scout your dream job!

An AI agent that does the job-search legwork. Upload your CV once. Every hour, or once a day, it finds fresh jobs, scores each one against your CV the way an applicant tracking system would, and emails you a tailored CV and cover letter for the best matches.

It never applies or contacts anyone for you. You stay in control of every application.

TypeScriptPlaywrightClaude APIGitHub Actions

What it does

Five steps on every run, with no one having to start it.

  1. Finds fresh jobs

    On the company job boards you choose: Greenhouse, Ashby and Lever through their public APIs, plus Built In pages read with a real browser.

  2. Filters them

    By title, location or remote, how old the posting is, deal-breaker words such as a security clearance, and companies you already applied to.

  3. Scores them like an ATS

    Checks which of the job’s hard-skill keywords your CV contains, and puts the best matches first.

  4. Tailors your CV

    Claude rewrites your CV and writes a cover letter for each top match, using only facts from your CV. Both are saved as PDFs.

  5. Emails you a digest

    With the PDFs attached and the skill gaps to prepare. It remembers what it sent, so you never get the same job twice.

How it works

Each stage is its own small module, so one part can change or fail without breaking the rest.

  1. config + CVYour targets, job boards and CV
  2. sourcesBoard APIs and Built In pages, collected with Playwright
  3. matchFilters and an ATS-style keyword score pick the top matches
  4. aiClaude writes the tailored CV, cover letter and skill gaps
  5. renderMarkdown to HTML to PDF, in Playwright’s Chromium
  6. notifyAn email digest, and a record of jobs already sent

Built to run on its own, safely

The decisions that make it safe to leave running without watching it.

No invented experience

The AI may use only facts from your CV. A fabrication check flags any skill it added that your CV never had.

One failure doesn’t stop the run

If one job board is down, the others still run. A job whose tailoring failed is retried on the next run.

Costs stay capped

A setting limits how many AI calls each run can make, and daily mode skips the heavy setup during off-hours.

No repeats

It keeps a record of every job it has sent, so each one reaches you only once.

Private by design

Your CV can live in a private repository or a GitHub secret. Tailored CVs are kept as run files only in private repositories.

No server to pay for

It runs on a schedule in GitHub Actions, with an optional settings page for editing settings, running searches and downloading PDFs.
