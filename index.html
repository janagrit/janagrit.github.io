Adversarial evaluation of an AI voice agent

A DeepEval harness that attacks a voice assistant with data-driven scenarios and measures it with custom disclosure metrics, so unsafe behavior is caught by tests, not by customers. Strict agent contained 10/10 attacks; the lax agent leaked as an intentional control. A regression gate fails the build if any metric drops below baseline.

Built with Python, DeepEval, Playwright + TypeScript (e2e through the UI), GitHub Actions
