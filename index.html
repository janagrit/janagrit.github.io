Services

Need help with a test suite? I also take on consulting projects.

Most teams have tests. Few trust them. Red builds get re-run until they pass, and real bugs still reach customers. These are the three ways I usually help.

01

Framework from scratch

A Playwright and TypeScript framework built around your critical user flows, with API mocking, smoke and regression suites, running on every pull request.

9 weeks to a full end-to-end framework for a legal-tech platform

02

Flaky-suite rescue

An audit of why your tests fail, then fixes at the root: isolated test data, stable auth sessions, real waits instead of sleeps, so a red build means a real bug.

60% fewer false-positive failures on a Java/Selenium suite

03

Migration to Playwright

Move from Cypress or Selenium without freezing feature work: suite by suite, with parallel runs and faster feedback at each step.

45% more automated coverage after a Cypress migration

  1. AuditI read your code, CI and tests, and you get a written plan with scope and timeline.
  2. BuildChanges land as small, reviewed pull requests, with a weekly update on what runs and what it caught.
  3. HandoverDocs, a recorded walkthrough and pairing, so your team owns the suite after I leave.

Also available: API and contract testing, resilience tests for event-driven AWS workflows, and setting up AI-assisted test workflows with Claude Code and MCP.
